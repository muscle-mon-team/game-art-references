두 작품을 복제하거나 화면을 그대로 합치는 제안이 아닙니다. REF-01은 측면 무대에서 큰 앞쪽 형태와 배경을 구분하는 기준, REF-02는 형태와 색 역할을 단순하게 정리하는 기준으로만 사용합니다.

## 첫 화면을 만든다면

아래는 승인 전 범위 제안입니다.

1. 현재 플레이어를 비교용으로 놓고 바닥과 가까운 사탕 소품의 형태, 재질과 조명을 비교
2. 기존 적 하나와 탄환을 함께 놓아 인물과 공격이 배경에서 읽히는지 확인
3. 기존 카메라와 해상도에서 변경 전후 실제 실행 화면 비교

기존 주인공은 비교용으로 사용할 수 있으나 최종 외형 유지 결정은 아닙니다. 종이 섬유와 맞춤 캐릭터 모델의 재현, 전체 적과 보스의 교체는 이 첫 범위에 자동으로 포함되지 않습니다. 다른 모델이 필요하면 실제 리소스 확보와 제작 부담부터 확인합니다.
